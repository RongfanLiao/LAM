Since `need_mask=True`:

- **If the image has < 4 channels** (no alpha): loads the mask from `mask_path`. Pixel values > 180 are thresholded to 255 (binary mask), everything else becomes 0. If no `mask_path` is given, it falls back to `rembg` (a background-removal library) to auto-generate a mask.
- **If the image has 4 channels** (RGBA): extracts the alpha channel as the mask.
- The mask is normalized to `[0.0, 1.0]` and squeezed to 2D `[H, W]`.

At the call site, `mask_path` is provided (from FLAME tracking output), so the mask is loaded from disk.

### 5. Apply Mask as Background Compositing (lines 153-155)

```python

```

Composites the foreground (where mask > 0) over a white background (`bg_color=1.0`). This removes any existing background and replaces it with solid white. Only the first 3 channels (RGB) are kept.

### 6. Center-Crop to Target Aspect Ratio (line 162)

```python
rgb, mask, offset_x, offset_y = center_crop_according_to_mask(
    rgb, mask, aspect_standard, enlarge_ratio

```

This is a key step. The helper `center_crop_according_to_mask` (line 61-116):

1. Finds the bounding box of the foreground mask (non-zero pixels).
2. Computes the image center.
3. Calculates half-widths from center to the farthest mask edge in each direction.
4. Adjusts the crop dimensions to match `aspect_standard` (1.0 at the call site, meaning a **square** crop).
5. If `enlarge_ratio != [1.0, 1.0]`, it randomly scales the crop window within that range (for data augmentation). At the call site both values are `1.0`, so **no random enlargement** occurs.
6. Crops the image and mask symmetrically around the center.

**Purpose**: Ensures the face is centered and the image has the correct aspect ratio, tightly framing the subject.

## Deep Dive: `shape_param`

### Content

`shape_param` is a **1D float tensor of shape `(300,)`** containing the **FLAME identity shape coefficients** (also called "betas").

It is loaded from `canonical_flame_param.npz` — a file produced during FLAME tracking export ([export_as_nerf_dataset.py:314-329](vhap/export_as_nerf_dataset.py#L314-L329)):

```python
# what's stored in canonical_flame_param.npz:
{
    'shape': np.float32 array of shape (300,),   # <-- this is shape_param
    'expr':  zeros (1, 100),   # neutral expression
    'rotation': zeros,         # neutral pose
    'jaw_pose': [[0.3, 0, 0]], # slightly open mouth
    ...
}
```

The 300 values are **PCA coefficients** in the FLAME statistical shape space. FLAME's shape model was built from ~4000 3D head scans. Each coefficient controls one principal component of shape variation — things like overall head size, face width, nose length, jaw shape, forehead height, etc. The first components capture the largest variance (e.g., overall proportions), later components capture finer details.

### Role Inside the FLAME Model

In [flame.py:615-627](lam/models/rendering/flame_model/flame.py#L615-L627), `shape_param` directly deforms the template mesh vertices:

```python
betas = torch.cat([shape, expr], dim=1)        # (300 + 100 = 400)
v_shaped = template_vertices + blend_shapes(betas, self.shapedirs)
#           ↑ generic head mesh     ↑ linear blend: shapedirs @ betas
```

- `self.shapedirs` is a tensor of shape `(V, 3, 400)` where `V` is the number of mesh vertices (~5023 for FLAME).
- `shapedirs[:, :, :300]` — **identity shape basis**: per-vertex 3D displacement vectors for each of the 300 PCA components. These encode structural face geometry (bone structure, skull shape, etc.).
- `shapedirs[:, :, 300:400]` — **expression basis**: per-vertex displacements for 100 expression blendshapes (smile, frown, blink, etc.). This is a separate concern from identity.

The `blend_shapes` function computes: `shapedirs @ betas` — a linear combination of basis vectors weighted by the coefficients, producing per-vertex offsets that are added to the generic template mesh.

### Why It Matters for LAM

LAM performs **cross-identity motion transfer**: take a source face image, animate it with a driving motion sequence. The `shape_param` ensures:

1. **Canonical mesh construction** — `get_cano_verts(shape_param)` builds the identity-specific rest-pose mesh that Gaussian splats are anchored to. Without the correct shape, splats would be positioned on a wrong face geometry.
2. **Consistent identity across frames** — the same betas are broadcast to all motion frames (`flame_params["betas"] = shape_param`), so the face identity stays fixed while expressions/poses change frame by frame.
3. **Correct deformation** — without the right betas, the driving motion would be applied to a generic average face, causing artifacts at the identity boundary (wrong jaw width, nose size, etc.).

In short: `shape_param` is **the 3D identity fingerprint** of the source face — it tells the FLAME model "what shape of head this person has" so animations can be applied correctly to that specific individual.
