# Explanation of `face_uv_coords = face_vertices(vertex_uvs[None], face_uvs_idx[None])[0]`

## `face_vertices` function

Defined in `lam/models/rendering/flame_model/flame.py:74-92`, this is a gather/indexing operation that converts **per-vertex** data into **per-face** data. Given a list of vertex attributes and a face index array (each face has 3 vertex indices), it looks up the 3 vertex attributes for every face.

```python
def face_vertices(vertices, faces):
    """
    :param vertices: [batch size, number of vertices, 3]
    :param faces: [batch size, number of faces, 3]
    :return: [batch size, number of faces, 3, 3]
    """
    bs, nv = vertices.shape[:2]
    bs, nf = faces.shape[:2]
    device = vertices.device
    faces = faces + (torch.arange(bs, dtype=torch.int32).to(device) * nv)[:, None, None]
    vertices = vertices.reshape((bs * nv, 3))
    return vertices[faces.long()]
```

1. **`vertex_uvs`** — shape `(V, 3)`: the UV coordinates for each vertex (2D UV + 1 padding column added earlier via `torch.cat([vertex_uvs, pad], dim=-1)`).

2. **`face_uvs_idx`** — shape `(F, 3)`: for each of the `F` faces, the 3 indices into `vertex_uvs` that form that triangle.

3. **`[None]`** — adds a batch dimension, turning shapes into `(1, V, 3)` and `(1, F, 3)`, since `face_vertices` expects a batch dimension.

4. **`face_vertices(...)`** — uses `face_uvs_idx` to index into `vertex_uvs`, gathering the 3 UV coordinates per face. Returns shape `(1, F, 3, 3)` — i.e., for each face, the 3 vertices' UV coords (each of dim 3).

5. **`[0]`** — removes the batch dimension, giving final shape `(F, 3, 3)`.

## Result
