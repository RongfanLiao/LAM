## What is `FlameUvMask`?

`FlameUvMask` is a container that loads **pre-computed boolean masks in UV texture space** for the FLAME face mesh. Each mask is a 2D grid (matching the UV texture resolution) where `True` marks texels belonging to a specific semantic region (e.g., sclerae, lips, face).

This is conceptually similar to `FlameMask` (which operates on vertices and faces), but works directly in **UV image space** — making it suitable for applying region-specific operations on the texture map.

## Class definition

```python
class FlameUvMask(BufferContainer):
    def __init__(self, uv_mask_path="model_zoo/.../uv_masks.npz"):
        uv_masks = np.load(uv_mask_path, allow_pickle=True)
        for region_name, uv_mask in uv_masks.items():
            self.register_buffer(region_name, torch.tensor(uv_mask, dtype=torch.bool))

    def get_uvmask_by_region(self, regions):
        """Get uv masks by regions (union of multiple regions)"""
        if isinstance(regions, str):
            regions = [regions]
        return torch.cat([self.get_buffer(k)[..., None] for k in regions], dim=-1).max(dim=-1)[0]
```

- Loads `uv_masks.npz`, which contains named boolean arrays — one per semantic region.
- Each mask is registered as a buffer named by its region (e.g., `self.sclerae`, `self.face`, etc.).
- `get_uvmask_by_region(regions)` returns the **union** of one or more region masks (via element-wise max).

## How it's used in the tracker

### 1. Texture residual regularization for specific regions

```python
# tracker.py:623-625
mask_sclerae = self.flame_uvmask.get_uvmask_by_region(self.cfg.w.reg_tex_res_for)[None, :, :]
reg_tex_res_clusters = self.tex_extra ** 2 * mask_sclerae
log_dict["reg_tex_res_clusters"] = self.cfg.w.reg_tex_res_clusters * reg_tex_res_clusters.mean()
```

This applies an L2 regularization penalty on the learnable residual texture (`tex_extra`), but **only within specific UV regions** (e.g., sclerae). This prevents the texture from drifting too far from the base in sensitive areas while allowing free optimization elsewhere.

## Purpose

`FlameUvMask` enables **region-selective texture operations in UV space**. Instead of treating the entire texture map uniformly, the tracker can:

- Apply different regularization strengths to different facial regions
- Mask out regions that shouldn't be optimized (e.g., occluded areas, eyeballs)
- Focus texture losses on specific areas of interest

This is essential because different facial regions have different texture characteristics — e.g., sclerae should remain white and smooth, while skin areas need more freedom to capture per-identity appearance.
