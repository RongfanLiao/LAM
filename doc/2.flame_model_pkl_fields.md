# FLAME Model `.pkl` Fields Reference

When the FLAME model file is loaded with:

```python
with open(flame_model_path, "rb") as f:
    ss = pickle.load(f, encoding="latin1")
    flame_model = Struct(**ss)
```

the resulting `ss` dictionary contains the following fields. All fields are **pre-trained, fixed** parameters that define the statistical head model — they are **not** optimized at runtime.

---

## Overview of FLAME

FLAME (Faces Learned with an Articulated Model and Expressions) is a statistical 3D head model from MPI. It factorizes head shape into:

$$\mathbf{v} = \text{LBS}\left(\mathbf{v}_\text{template} + B_S(\beta) + B_E(\psi) + B_P(\theta),\ \theta,\ \mathbf{W}\right) + \mathbf{t}$$

where $B_S$ = shape blend shapes, $B_E$ = expression blend shapes, $B_P$ = pose blend shapes, and LBS = linear blend skinning.

---

## Field-by-Field Reference

### `v_template`
- **Shape:** `(V, 3)` — `V ≈ 5023` vertices, each with `(x, y, z)` coordinates
- **Type:** float array
- **Description:** The **mean/neutral head mesh** in the canonical pose (no expression, no rotation). All other FLAME parameters produce displacements **on top of** this template.
- **Used as:** `self.v_template` — the base mesh that all blend shapes and skinning deform.

```python
self.register_buffer("v_template", to_tensor(to_np(flame_model.v_template), dtype=self.dtype))
```

---

### `f`
- **Shape:** `(F, 3)` — `F ≈ 9976` triangular faces, each a triplet of vertex indices
- **Type:** int array (uint32 / int64)
- **Description:** The **face/triangle connectivity** of the mesh. Defines which 3 vertices form each triangle. This topology is fixed and shared across all FLAME instances.
- **Used as:** `self.faces` — also cross-checked via assertion against the loaded `.obj` template mesh.

```python
assert (self.faces == torch.from_numpy(flame_model.f.astype('int64'))).all()
```

---

### `shapedirs`
- **Shape:** `(V, 3, 400)` — 300 shape PCA components + 100 expression PCA components
- **Type:** float array
- **Description:** The **blend shape basis** (PCA directions) for both identity shape and facial expressions. Each of the 400 columns is a `(V×3)` displacement vector.

  - Columns `[0:300]` → **identity shape** directions (controlled by `shape` / $\beta$ parameters)
  - Columns `[300:400]` → **expression** directions (controlled by `expr` / $\psi$ parameters)

  The blend shape contribution is:

  $$B_S(\beta) + B_E(\psi) = \sum_{i=0}^{299} \beta_i \cdot \mathbf{s}_i + \sum_{j=0}^{99} \psi_j \cdot \mathbf{e}_j$$

- **Used as:** `self.shapedirs` — sliced at load time to keep only `shape_params` + `expr_params` components.

```python
shapedirs = to_tensor(to_np(flame_model.shapedirs), dtype=self.dtype)
shapedirs = torch.cat([shapedirs[:, :, :shape_params], shapedirs[:, :, 300:300+expr_params]], 2)
self.register_buffer("shapedirs", shapedirs)
```

---

### `posedirs`
- **Shape:** `(V*3, (J-1)*9)` — vertices×coords vs. pose feature dimensions
- **Type:** float array
- **Description:** The **pose-corrective blend shape** basis. Pose rotations create artifacts (e.g., volume loss at joints), so `posedirs` provides learned **linear corrections** based on the rotation matrices. For each of the `J-1 = 4` non-global joints, each rotation matrix contributes a `3×3 = 9` dimensional feature, giving `(J-1)×9 = 36` pose features total.

  The pose-dependent offset is:

  $$B_P(\theta) = \mathbf{P} \cdot \text{vec}(R_1 - I,\ R_2 - I,\ \ldots,\ R_{J-1} - I)$$

  where $R_k$ is the rotation matrix for joint $k$ and $\mathbf{P}$ is the `posedirs` matrix.

- **Used as:** `self.posedirs` — reshaped to `((J-1)*9, V*3)` (transposed) before storing.

```python
num_pose_basis = flame_model.posedirs.shape[-1]
posedirs = np.reshape(flame_model.posedirs, [-1, num_pose_basis]).T
self.register_buffer("posedirs", to_tensor(to_np(posedirs), dtype=self.dtype))
```

---

### `J_regressor`
- **Shape:** `(J, V)` — `J = 5` joints, `V ≈ 5023` vertices
- **Type:** sparse or dense float array
- **Description:** A **linear regressor** that computes 3D joint locations from the shaped mesh vertices. Each row $j$ contains weights that, when applied to all vertex positions, yields the 3D position of joint $j$:

  $$\mathbf{J} = \mathbf{W}_\text{reg} \cdot \mathbf{V}_\text{shaped}$$

  The 5 joints are (in order):
  | Index | Joint |
  |-------|-------|
  | 0 | Global head root |
  | 1 | Neck |
  | 2 | Jaw |
  | 3 | Left eyeball |
  | 4 | Right eyeball |

- **Used as:** `self.J_regressor`

```python
self.register_buffer("J_regressor", to_tensor(to_np(flame_model.J_regressor), dtype=self.dtype))
```

---

### `kintree_table`
- **Shape:** `(2, J)` — 2 rows (parent/child), `J = 5` joints
- **Type:** int array
- **Description:** Defines the **skeletal kinematic tree** (parent-child hierarchy). `kintree_table[0]` contains the parent index for each joint. The root joint (index 0) has its parent set to `-1`.

  The FLAME kinematic chain:
  ```
  global (0)
    └── neck (1)
          └── jaw (2)
          └── left eye (3)
          └── right eye (4)
  ```

- **Used as:** `self.parents` (only row `[0]` is used, with `parents[0] = -1` manually set)

```python
parents = to_tensor(to_np(flame_model.kintree_table[0])).long()
parents[0] = -1
self.register_buffer("parents", parents)
```

---

### `weights`
- **Shape:** `(V, J)` = `(V, 5)` — one weight per vertex per joint
- **Type:** float array
- **Description:** The **Linear Blend Skinning (LBS) weights**. Each row is a probability distribution (sums to 1.0) encoding how much each joint's rigid transformation influences a given vertex. Vertices near the jaw bone get high `weights[:, 2]`; eye-region vertices get high `weights[:, 3]` or `weights[:, 4]`.

  Used in the skinning equation:

  $$\mathbf{v}'_i = \left(\sum_{k=0}^{J-1} W_{ik} \cdot \mathbf{G}_k\right) \mathbf{v}_i$$

  where $\mathbf{G}_k$ is the world-space transformation of joint $k$.

- **Used as:** `self.lbs_weights`. The code also manually **extends** this matrix when adding teeth, oral cavity, and shoulder meshes by appending rows and assigning them to specific joints.

```python
self.register_buffer("lbs_weights", to_tensor(to_np(flame_model.weights), dtype=self.dtype))
```

## Summary Table

| Field | Shape | Description |
|---|---|---|
| `v_template` | `(V, 3)` | Neutral/mean head mesh vertices |
| `f` | `(F, 3)` | Triangle face connectivity (vertex indices) |
| `shapedirs` | `(V, 3, 400)` | PCA blend shape basis: `[:300]` = identity, `[300:400]` = expression |
| `posedirs` | `(V*3, 36)` | Pose-corrective blend shape basis (36 = 4 joints × 9 rotation matrix elements) |
| `J_regressor` | `(5, V)` | Linear regressor: shaped vertices → 5 joint positions |
| `kintree_table` | `(2, 5)` | Kinematic tree parent indices for 5 joints |
| `weights` | `(V, 5)` | LBS skinning weights: per-vertex influence of each joint |

## FLAME Parameter Inputs at Runtime

These are the **per-frame inputs** passed to the model during tracking/inference — **not** stored in the `.pkl`:

| Parameter | Shape | Description |
|---|---|---|
| `shape` / $\beta$ | `(300,)` | Identity shape coefficients (person-specific, fixed per subject) |
| `expr` / $\psi$ | `(N, 100)` | Expression blend shape coefficients per frame |
| `rotation` | `(N, 3)` | Global head rotation (axis-angle) |
| `neck_pose` | `(N, 3)` | Neck joint rotation (axis-angle) |
| `jaw_pose` | `(N, 3)` | Jaw joint rotation (axis-angle) |
| `eyes_pose` | `(N, 6)` | Left + right eye rotations (axis-angle, 3 each) |
| `translation` | `(N, 3)` | Global head translation |
| `static_offset` | `(1, V, 3)` | Per-vertex personalized geometry offset (optional) |
