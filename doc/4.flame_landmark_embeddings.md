# FLAME Landmark Embeddings Explained

This document explains the `lmk_embeddings` loaded from `landmark_embedding_with_eyes.npy` and how they are used in FLAME tracking.

---

## 1. What is `lmk_embeddings`?

```python
lmk_embeddings = np.load(flame_lmk_embedding_path, allow_pickle=True, encoding="latin1")
lmk_embeddings = lmk_embeddings[()]
```

It is a dictionary with **two keys**, defining where ~68–70 semantic facial landmarks sit on the FLAME mesh surface:

| Key | Shape | Type | Description |
|-----|-------|------|-------------|
| `full_lmk_faces_idx` | `(L,)` | `int64` | For each landmark, the **index of the triangle face** it belongs to |
| `full_lmk_bary_coords` | `(L, 3)` | `float32` | For each landmark, the **barycentric coordinates** within that face |

where `L ≈ 68–70` is the number of landmarks (68 standard facial + optional 2 pupil landmarks).

---

## 2. Why Barycentric Coordinates, Not Vertex Indices?

Facial landmarks (nose tip, eye corners, lip edges, jawline points, etc.) almost never fall **exactly on a mesh vertex**. They sit at arbitrary positions **inside a triangle face**, between vertices.

**Barycentric coordinates** $(w_1, w_2, w_3)$ with $w_1 + w_2 + w_3 = 1$ encode the exact position within a triangle:

$$\mathbf{p}_\text{landmark} = w_1 \cdot \mathbf{v}_0 + w_2 \cdot \mathbf{v}_1 + w_3 \cdot \mathbf{v}_2$$

where $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$ are the 3 vertex positions of the triangle.

### Visual Intuition

```
        v0
       / \
      /   \
     / ·p  \      p = 0.3·v0 + 0.5·v1 + 0.2·v2
    /       \         (barycentric coords: [0.3, 0.5, 0.2])
   v1───────v2
```

Special cases:
- `(1, 0, 0)` → exactly at vertex $v_0$
- `(0.5, 0.5, 0)` → midpoint of edge $v_0 v_1$
- `(1/3, 1/3, 1/3)` → centroid of the triangle

This approach is **mesh-resolution independent**: the same barycentric embedding works whether the mesh is subdivided (upsampled) or not, as long as the face topology is consistent.

## 3. How Landmarks Are Computed — `vertices2landmarks()`

```python
def vertices2landmarks(vertices, faces, lmk_faces_idx, lmk_bary_coords):
```

Given a **deformed** FLAME mesh, this function extracts 3D landmark positions:

### Step-by-step

1. **Look up face vertices:** For each landmark $l$, use `lmk_faces_idx[l]` to find which triangle face it belongs to, then gather the 3 vertex indices from `faces`:

   ```python
   lmk_faces = torch.index_select(faces, 0, lmk_faces_idx.view(-1))
   # shape: (L, 3) — three vertex indices per landmark
   ```

2. **Gather 3D positions:** Look up the actual $(x, y, z)$ positions of those vertices from the deformed mesh:

   ```python
   lmk_vertices = vertices.view(-1, 3)[lmk_faces]
   # shape: (B, L, 3, 3) — for each landmark, 3 vertices × 3 coords
   ```

3. **Barycentric interpolation:** Weighted sum using the stored barycentric coordinates:

   ```python
   landmarks = torch.einsum("blfi,blf->bli", lmk_vertices, lmk_bary_coords)
   # shape: (B, L, 3) — 3D position of each landmark
   ```

   This computes: $\mathbf{p}_l = w_1 \cdot \mathbf{v}_0 + w_2 \cdot \mathbf{v}_1 + w_3 \cdot \mathbf{v}_2$ for each landmark.

### Called from the FLAME forward pass

```python
# In FlameHead.forward(), when return_landmarks=True:
landmarks = vertices2landmarks(
    vertices,                                    # (B, V, 3) — deformed mesh
    self.faces,                                  # (F, 3) — face connectivity
    self.full_lmk_faces_idx.repeat(bz, 1),       # (B, L) — face index per landmark
    self.full_lmk_bary_coords.repeat(bz, 1, 1),  # (B, L, 3) — barycentric weights
)
```

## 4. Why It Matters — The Landmark Loss in Tracking

The landmark embeddings are the **bridge** between 2D image landmarks and 3D FLAME parameters. They enable the core supervision signal for FLAME fitting:

### The Tracking Pipeline

```
┌─────────────────────────────────────────────────────────────────┐
│  Input Image                                                    │
│       │                                                         │
│       ▼                                                         │
│  2D Landmark Detector (external/landmark_detection/)            │
│       │                                                         │
│       ▼                                                         │
│  Ground Truth 2D Landmarks  ──────────────┐                     │
│  (lmk2d: shape (B, 68, 3))               │  L1 loss            │
│  with (x, y, confidence)                  │                     │
│                                           ▼                     │
│                                     ┌───────────┐              │
│                                     │  lmk_loss │              │
│                                     └─────┬─────┘              │
│                                           ▲                     │
│  FLAME Parameters ──► forward() ──►      │                     │
│  (shape, expr,        3D Mesh      Predicted 2D Landmarks      │
│   pose, ...)            │          (pred_lmk2d)                │
│                         │                ▲                      │
│                         ▼                │                      │
│              vertices2landmarks()  ──► project ──► 2D           │
│              (uses lmk_embeddings)   (camera K, RT)            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### In Code (`tracker.py` → `compute_lmk_energy()`)

```python
def compute_lmk_energy(self, sample, pred_lmks, disable_jawline_landmarks=False):
    # 1. Ground truth: 2D landmarks detected in the image
    lmk2d = sample["lmk2d"]        # (B, 68+, 3) — x, y, confidence
    
    # 2. Predicted: 3D landmarks from FLAME → projected to 2D
    pred_lmk_ndc = self.render.world_to_ndc(pred_lmks, RT, K, img_size)
    pred_lmk2d = pred_lmk_ndc[:, :, :2]
    
    # 3. Loss: L1 distance weighted by detection confidence
    diff = lmk2d[:, :68, :2] - pred_lmk2d[:, :68]
    lmk_loss = torch.norm(diff, dim=2, p=1) * confidence
    
    return lmk_loss.mean()
```

### What the loss optimizes

By minimizing this landmark loss, the optimizer adjusts:
- **`shape` ($\beta$):** face width, nose length, etc. — to match the person's identity
- **`expression` ($\psi$):** smile, brow raise, etc. — to match the facial expression
- **`rotation`, `jaw_pose`, `neck_pose`:** head/jaw orientation
- **`translation`:** head position in 3D space
- **`eyes_pose`:** gaze direction (if pupil landmarks are used)

## 5. The 68 (+ 2) Landmark Layout

The standard 68-point facial landmark convention:

```
Landmarks 0–16:   Jawline contour (17 points)
Landmarks 17–21:  Left eyebrow (5 points)
Landmarks 22–26:  Right eyebrow (5 points)
Landmarks 27–30:  Nose bridge (4 points)
Landmarks 31–35:  Nose bottom (5 points)
Landmarks 36–41:  Left eye (6 points)
Landmarks 42–47:  Right eye (6 points)
Landmarks 48–59:  Outer lip (12 points)
Landmarks 60–67:  Inner lip (8 points)
Landmarks 68–69:  Pupil centers (2 points, optional)
```

The file is named `landmark_embedding_with_eyes.npy` because it includes the **two extra pupil landmarks** (68–69) beyond the standard 68-point set. Eye landmarks have their confidence doubled in the loss (`confidence[:, 68:] *= 2`) for better gaze tracking.

## 6. Summary

| Concept | Detail |
|---------|--------|
| **What** | Pre-computed mapping from ~70 facial landmarks to positions on the FLAME mesh surface |
| **How** | Each landmark is defined by a face index + barycentric coordinates within that face |
| **Why barycentric** | Landmarks don't fall on vertices — they lie at arbitrary positions inside triangles |
| **Used in** | `vertices2landmarks()` — extracts 3D landmark positions from any deformed FLAME mesh |
| **Purpose** | Enables the **landmark loss** in FLAME tracking: compare projected 3D landmarks against detected 2D landmarks to optimize FLAME parameters |
| **Differentiable** | Yes — barycentric interpolation is fully differentiable, allowing gradient-based optimization |
