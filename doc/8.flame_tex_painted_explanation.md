## What is `FlameTexPainted`?

`FlameTexPainted` is a simple `nn.Module` that loads a **pre-painted mean texture image** for the FLAME face mesh and serves it as a fixed (non-learnable) UV texture map. The texture image is loaded from:

```
model_zoo/human_parametric_models/flame_vhap/tex_mean_painted.png
```

This is a hand-painted or artist-created average face texture in UV space, as opposed to the PCA-based statistical texture model (`FlameTexPCA`).

## Class internals

```python
class FlameTexPainted(nn.Module):
    def __init__(self, tex_size=512, painted_tex_path=FLAME_PAINTED_TEX_PATH):
        tex_painted = Image.open(painted_tex_path)  # load PNG image
        # normalize to [0, 1], reshape to (1, 3, H, W)
        # resize to tex_size x tex_size if needed
        self.register_buffer("tex_painted", tex_painted)

    def forward(self):
        return self.tex_painted  # shape: (1, 3, tex_size, tex_size)
```

- Loads the PNG texture, extracts the RGB channels, normalizes pixel values to `[0, 1]`.
- Resizes to `tex_size x tex_size` (controlled by `cfg.model.tex_resolution`) if the original image dimensions differ.
- Stores the result as a non-learnable buffer of shape `(1, 3, tex_size, tex_size)`.
- `forward()` simply returns this fixed texture.

## How it's used in the tracker

The tracker chooses between two texture models based on `cfg.model.tex_painted`:

```python
# Initialization (tracker.py:57-60)
if cfg.model.tex_painted:
    self.flame_tex_painted = FlameTexPainted(...)
else:
    self.flame_tex_pca = FlameTexPCA(...)
```

At render time, `get_base_texture()` fetches the base albedo:

```python
# tracker.py:314-322
def get_base_texture(self):
    if self.cfg.model.tex_extra and not self.cfg.model.residual_tex:
        albedos_base = self.tex_extra[None, ...]
    else:
        if self.cfg.model.tex_painted:
            albedos_base = self.flame_tex_painted()    # fixed painted texture
        else:
            albedos_base = self.flame_tex_pca(...)     # PCA-generated texture
    return albedos_base
```

Then `get_albedo()` optionally adds a learnable residual texture (`tex_extra`) on top of the base:

```python
# tracker.py:324-335
def get_albedo(self):
    albedos_base = self.get_base_texture()
    if self.cfg.model.tex_extra and self.cfg.model.residual_tex:
        albedos = albedos_base + self.tex_extra[None, :]
    else:
        albedos = albedos_base
    return albedos
```

## Purpose

| Texture mode | Description |
|---|---|
| **`FlameTexPainted`** | Fixed pre-painted mean texture. Not parameterized — serves as a constant base. Simpler, no PCA coefficients to optimize. |
| **`FlameTexPCA`** | Statistical PCA-based texture model with learnable coefficients, generating textures from a linear combination of basis textures. |

`FlameTexPainted` is typically used as a **fixed initialization / base layer** for the face albedo. When `residual_tex` is enabled, a learnable per-texel residual (`tex_extra`) is added on top, allowing the tracker to refine the texture for a specific identity while starting from a reasonable mean face appearance.
