# Explanation of `FlameMask` Construction

Source: `vhap/model/flame.py:170-176`

```python
self.mask = FlameMask(
    faces=self.faces,
    faces_t=self.textures_idx,
    num_verts=self.v_template.shape[0],
    num_faces=self.faces.shape[0],
    face_clusters=face_clusters,
)
```

## What is `FlameMask`?

`FlameMask` (defined at `vhap/model/flame.py:711`) is an `nn.Module` that provides **semantic region masks** for the FLAME 3D face mesh. It partitions the mesh's vertices, faces, and UV-texture coordinates into named semantic regions (e.g., face, neck, lips, eyes, hair, skin, etc.), enabling region-specific processing during rendering, loss computation, or texture manipulation.

## Constructor Parameters

| Parameter | Value Passed | Description |
|---|---|---|
| `faces` | `self.faces` | Face index tensor of shape `(F, 3)`. Each row contains 3 vertex indices defining a triangle. |
| `faces_t` | `self.textures_idx` | Texture face index tensor of shape `(F, 3)`. Each row contains 3 UV-vertex indices for the same triangle, used to map faces to UV space. |
| `num_verts` | `self.v_template.shape[0]` | Total number of vertices in the mesh (typically 5023 for standard FLAME). |
| `num_faces` | `self.faces.shape[0]` | Total number of faces/triangles in the mesh (typically 9976). |
| `face_clusters` | `face_clusters` | A list of region names (e.g., `["lips", "eye_region"]`) used to assign each face to a cluster ID for grouped processing. |

## What Happens During Initialization

The constructor triggers four processing steps:

### 1. `process_vertex_mask()` — Load and extend vertex masks

- Loads pre-defined vertex masks from the FLAME model's `.npy` file. These masks include: `face`, `neck`, `scalp`, `boundary`, `right_eyeball`, `left_eyeball`, `right_ear`, `left_ear`, `forehead`, `eye_region`, `nose`, `lips`, `right_eye_region`, `left_eye_region`.
- Calls `create_custom_mask()` to define additional masks such as: `lip_inside`, `lip_outside_ring_upper/lower`, `left/right_eyelid`, `left/right_iris`, `left/right_half`, `hair`, `skin`, `eyelids`, `sclerae`, etc.
- All masks are stored as buffers under `self.v.<region_name>` — each is a 1D tensor of vertex indices belonging to that region.

### 2. `construct_vid_table()` — Build reverse lookup

- Builds `self.vid_to_region`: a dictionary mapping each vertex ID to a list of region names it belongs to.
- This reverse index is used by the face mask and vt mask processing below.

### 3. `process_face_mask()` — Derive per-face region masks

- For each face (triangle), checks how many of its 3 vertices belong to each named region.
- If all 3 vertices of a face belong to a region (`count >= 3`), the face is assigned to that region.
- Results are stored as `self.f.<region_name>` — each is a 1D tensor of face indices.

### 4. `process_face_clusters()` — Assign cluster IDs to faces

- Creates a lookup table `self.fid2cid` mapping each face ID to a cluster ID:
  - Cluster `0`: background (not rendered)
  - Cluster `1`: foreground (default for all faces)
  - Cluster `2+`: faces belonging to specific regions listed in `face_clusters`
- This enables per-cluster rendering or loss weighting.

### 5. `process_vt_mask()` — Derive per-UV-vertex region masks

- For each face, maps each vertex's region membership to the corresponding UV-texture vertex ID (`faces_t`).
- Results are stored as `self.vt.<region_name>` — each is a 1D tensor of UV-vertex indices, useful for region-specific texture operations.

## Result

After construction, `self.mask` provides three levels of semantic masks:

- **`self.mask.v.<region>`** — Vertex-level masks (vertex indices per region)
- **`self.mask.f.<region>`** — Face-level masks (face indices per region)
- **`self.mask.vt.<region>`** — UV-texture-vertex-level masks (UV vertex indices per region)
- **`self.mask.fid2cid`** — Face-to-cluster-ID lookup table

These masks are used throughout the pipeline for tasks like selective rendering, per-region loss computation, and texture editing.
